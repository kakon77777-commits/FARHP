# FARHP WebLab MVP v0.8

FARHP WebLab 是可離線執行的「基頻錨定相對諧波相位差」華語合成、ABX 知覺研究與研究治理原型。

## v0.8 重點

- 研究計畫、排除政策與同意書版本共同鎖定並產生指紋。
- 電子同意與資格確認綁定鎖定計畫；不要求姓名、電子郵件或聯絡資料。
- 關鍵事件建立前後相接的雜湊鏈，可偵測順序或內容遭修改。
- 產生 SHA-256 封存證書；不支援 Web Crypto 時會明確標示備援演算法。
- 匯出去識別研究資料，將匿名代碼再轉換為研究專用單向假名。
- 群體資料合併新增同意、事件鏈、計畫指紋與刺激不變量品質審查。
- 匯出逐輪長表、R `lme4` GLMM 模板與 Python GEE 模板。
- 研究者、受試者、分析者三種介面視圖；這是工作流程分流，不是伺服器權限控制。

## 啟動

直接開啟 `index.html`，或執行：

```bash
python -m http.server 8000
```

再進入 `http://localhost:8000`。透過 localhost／HTTPS 開啟時可使用瀏覽器 Web Crypto 產生 SHA-256；某些直接檔案模式會退回清楚標記的備援指紋。

## 最小研究流程

1. 選擇刺激、條件、重複數與排除政策。
2. 固定同意書版本與摘要，鎖定研究計畫。
3. 切換到受試者介面，完成資格與電子同意。
4. 建立研究、進行練習與正式 ABX 試驗。
5. 匯出原始研究 JSON、去識別 JSON、逐輪 CSV 與事件封存證書。
6. 匯入多份研究 JSON，檢查治理品質並匯出長表與分析模板。

## 重要邊界

本工具不等於倫理委員會核准、法律有效的電子簽章、伺服器端存取控制或正式資料保管系統。若研究涉及真人、招募、補償、敏感資料或公開發表，仍須依所在地制度完成倫理、隱私與研究治理程序。

FARHP 是聲學相位子系統。網站目前使用結構型合成刺激，不代表真人語音或自然語料上的效果已獲證實。
