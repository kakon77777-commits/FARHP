# Changelog

## v0.8 — 2026-07-31

### Added

- 電子同意模板、版本、摘要與資格確認。
- 撤回代碼與同意紀錄；同意紀錄綁定計畫指紋。
- 研究者／受試者／分析者三種介面視圖。
- FNV32x8 即時事件鏈與 SHA-256 封存鏈。
- 事件鏈驗證、封存證書匯出與篡改偵測。
- 去識別研究 JSON；受試者與工作階段使用研究專用單向假名。
- 群體治理品質摘要：缺少同意、事件鏈失敗、計畫指紋問題、刺激不變量失敗與重複工作階段。
- 逐輪長表 CSV、R GLMM 模板、Python GEE 模板。
- 七份 v0.8 JSON Schema。

### Changed

- 研究計畫、檢查點、單人研究與群體分析交換格式升級為 v0.8。
- 群體匯入仍相容 v0.6 與 v0.7 單人研究格式。
- 建立正式研究前必須完成電子同意及資格確認。
- 檢查點加入同意狀態與事件鏈，但仍不保存音訊陣列。

### Limits

- 角色視圖不是身份驗證或真正權限隔離。
- 即時事件鏈使用同步備援雜湊；封存匯出才在可用時重算 SHA-256 鏈。
- 分析腳本是模板，不能取代預註冊與統計審查。
