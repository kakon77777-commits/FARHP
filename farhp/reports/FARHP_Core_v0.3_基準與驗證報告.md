# FARHP-Core v0.3 基準與驗證報告

**日期：** 2026-07-26  
**對應論文：** FARHP 系列第七篇

# 1. 版本新增

`FARHP-Core v0.3` 在 v0.2 的多框架追蹤之上新增：

- 圓周最短測地插值；
- 原相位、零相位、奇偶交替、固定隨機與平滑隨機條件；
- 不同長度 FARHP 軌跡的正規化時間對齊；
- 部分及完整相位風格移植；
- 變換後 FARHP 解除包覆與相位速度重算；
- 變換報告與不變量檢查；
- 匿名盲聽包；
- `FARHP-Transform-Spec-v0.3`；
- overlap-add 外緣低權重尖峰修正。

# 2. 核心幾何

$$
\operatorname{GI}_{S^1}(a,b;\lambda)
=
\operatorname{wrap}
\left(
a+\lambda\operatorname{wrap}(b-a)
\right).
$$

此式避免把 $170^\circ$ 至 $-170^\circ$ 的中點錯誤插值到 $0^\circ$。

# 3. 測試材料

內容軌跡：

- 近似 `/a/` 的動態合成母音；
- $1.20$ 秒；
- $113$ 框架；
- $f_0$ 約 $108$ 至 $162$ Hz；
- 最多 $18$ 個諧波。

風格軌跡：

- 近似 `/i/` 的動態合成母音；
- $0.90$ 秒；
- $83$ 框架；
- 加入 $0.85$ 強度的奇偶交替 FARHP 模板。

# 4. 不變量證書

完整相位風格移植時：

| 指標 | 結果 |
|---|---:|
| $f_0$ 逐框架精確保持 | `true` |
| 最大諧波振幅差 | $0$ |
| 最大錨相位差 | $0$ rad |
| 平均 FARHP 測地位移 | $0.908849$ rad |
| 最大 FARHP 測地位移 | $2.619044$ rad |

因此本次變換只改變 FARHP 與由其導出的動態相位欄位。

# 6. overlap-add 修正紀錄

初次產生比較材料時，檔案外緣出現不合理高峰均比。原因不是 FARHP，而是 Hann 類窗函數外緣權重接近零，舊版仍對極小權重執行除法，造成數值放大。

v0.3 改為只在：

$$
W[n]>10^{-3}\max W
$$

時除權，未獲充分窗支撐的外緣樣本設為零。新增回歸測試限制重建峰值，不再將此工程假象混入相位結果。

# 8. 盲聽包

輸出七個匿名 WAV，以及：

```text
public_manifest.json
rating_template.json
secret_key.json
trajectories/*.json
```

公開檔不包含條件名稱。秘密對照表保存隨機種子、條件映射、變換報告與客觀指標。

# 9. 可支持的結論

- FARHP-only 變換可被實作與驗證；
- 相位環面插值可形成連續控制路徑；
- 不同相位條件在固定 $f_0$ 與諧波振幅下產生不同波形；
- 不變量可以被程式化檢查；
- 盲聽材料可自動匿名化。

# 10. 不可支持的結論

- 尚未證明自然語音品質改善；
- 尚未證明人類必然可辨；
- 尚未完成多受試者統計；
- 尚未保持完整非諧波殘差；
- 尚未證明 FARHP 等同完整音色或說話者風格。
