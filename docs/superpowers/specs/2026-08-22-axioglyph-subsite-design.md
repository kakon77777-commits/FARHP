# Axioglyph 子網站設計規格

## 1. 定位

**Axioglyph｜理符** 是 EMPSL 的獨立對外品牌。名稱來自 *axiom* 與 *glyph*，主張「符號不是裝飾，而是可驗證的結構」。網站以繁體中文為主，保留必要英文術語，並在品牌旁標示 `Built on EMPSL v0.4`，但不以 EMPSL 縮寫要求一般訪客先具備背景知識。

首版採「雙層入口」：

1. 一般訪客在 60–90 秒內理解它是什麼、為何存在、能做什麼；
2. 研究者與工程使用者能深入互動實驗室、規則、語料、證書與版本路線圖。

## 2. 目標與非目標

### 目標

- 建立內容充足、可獨立辨識的 Axioglyph 品牌首頁。
- 將既有 EMPSL v0.4 Glyph Grammar Lab 納入同一條閱讀動線，不複製權威資料。
- 讓「了解系統」與「直接操作」都能從首頁一鍵抵達。
- 清楚呈現 128 原子、256 受控變體、30 條規則、4,096 筆驗證語料等現有證據。
- 修補既有互動的回饋缺口：案例載入、修正、變體切換與下載必須有可見且可被輔助技術讀取的結果。
- 保持部署位置中立：可作為現有網站內的子頁，也可把同一目錄部署成獨立子網域。

### 非目標

- 首版不決定正式網域、子網域或最終 URL。
- 不引入帳號、資料庫、後端 API、分析追蹤或 CMS。
- 不宣稱 EMPSL 是歷史語言復原、加密系統、自然語言標準或 production certification。
- 不把 v0.5 尚未完成的 Lexicon、Typed AST、Compiler 或 Decompiler 包裝成已交付功能。
- 不重寫 EMPSL 驗證核心、規則資料或 4,096 筆語料。

## 3. 架構決策

重構 `empsl/v0.4/index.html` 為完整靜態子網站，沿用現有 v0.4 資料與引擎。頁面拆成：

- `index.html`：語義化內容、導覽、雙層入口與實驗室 DOM；
- `assets/site.css`：品牌視覺、排版、響應式與互動狀態；
- `assets/site.js`：行動導覽、滾動顯示與非核心頁面增強；
- `assets/app.js`：既有 EMPSL 實驗室行為，以及操作／下載回饋；
- 現有 `data/`、`rules/`、`examples/` 與 `assets/empsl_core.js`：唯一的研究資料與驗證來源。

所有站內 URL 使用相對路徑，不使用 `/assets/...` 等根目錄絕對路徑。頁面透過 HTTP 提供時必須可在任意路徑前綴下運作。直接 `file://` 開啟不是正式驗收方式；README 要提供一行本機 HTTP 啟動指令。

## 4. 資訊架構

### 4.1 全域導覽

- 左側：Axioglyph｜理符與 `Built on EMPSL v0.4`。
- 主要錨點：概念、系統、實驗室、證據、路線圖。
- 主要按鈕：`進入實驗室`。
- 行動版提供可鍵盤操作的選單按鈕，狀態透過 `aria-expanded` 表達。

### 4.2 首屏

- 主標：`符號，不只是被畫出來。它可以被證明。`
- 一段話說明字形、華語音系、型別語義與 FARHP 聲學如何合成同一個可驗證配方。
- 雙 CTA：`先理解系統` 與 `直接進入實驗室`。
- 以程式原生 SVG／CSS 呈現品牌符號與六槽結構，不新增外部影像相依。
- 明示邊界：現代形式符號語言研究，不是神秘學字體或歷史語言復原。

### 4.3 一般訪客理解層

依序回答四個問題：

1. **它是什麼？** 一個可組合、可檢查、可重現的字形語言工程。
2. **它解決什麼？** 避免「看起來能拼」卻缺乏身份、語義與跨欄位一致性的符號。
3. **一個字形包含什麼？** 外框、種子、音系、相位、算子、語義／聲學物件。
4. **如何判定合法？** Schema 檢查結構；30 條規則檢查跨欄位關係；證書保留錯誤與警告。

本層使用四張概念卡、一個六槽解剖圖與一條「構形 → 驗證 → 證書 → 匯出」流程。

### 4.4 互動實驗室

保留現有全部欄位、合法／錯誤案例、自動修正、SVG／JSON 匯出、八個變體、完整配方與規則列表。

改善項目：

- 所有按鈕操作寫入 `aria-live` 活動訊息；
- 載入案例時回報案例 ID 與 PASS／FAIL；
- 自動修正回報修正後狀態；
- 變體卡具備按鈕語義、鍵盤焦點、`aria-pressed` 與選取樣式；
- 匯出使用實際附加到文件的暫時連結，完成後移除並撤銷 object URL；
- 匯出成功或失敗均有可見訊息；
- 驗證狀態本身使用 `role="status"`，錯誤列表可被輔助技術辨識。

### 4.5 研究證據層

- 128 個原子；
- 256 個受控種子變體；
- 30 條跨欄位合法性規則；
- 4,096 筆符合性語料；
- Node 核心測試與 Python 批次交叉檢查；
- 可追溯的 ruleset SHA-256 與 recipe SHA-256。

資料必須從現有註冊表與報告載入，能動態呈現者不得另寫一份易漂移的數值。文字要區分工程回歸證據與真人知覺／自然語音研究。

### 4.6 方法、邊界與路線圖

- 說明 Stable ID 不等於 PUA、字形輪廓或字型檔。
- 說明 Schema 與規則引擎的責任差異。
- 說明 FARHP 是聲學相位來源，不代表自然語音結論。
- v0.4 標為目前可工作節點。
- v0.5 僅列為方向：Versioned Lexicon、Typed AST、Type Inference、Compiler、Decompiler。
- FAQ 至少回答：是否為字型、是否為語言、是否為加密、是否能匯出、規則如何驗證、研究資料在哪裡。

## 5. 視覺系統

方向是「研究檔案館 × 活字鑄造室」：

- 深墨黑／靛灰為背景，暖象牙色作閱讀面；
- 氧化銅與訊號青作兩條導覽路徑的強調色；
- 標題使用系統 serif 字族，資料與介面使用系統 sans／monospace；
- 以細線、編號、檔案章、座標與大面積留白建立研究質感；
- 不使用科技產品常見的紫色漸層、玻璃卡片堆疊或無意義 3D 圖；
- 動效只用於理解層級與狀態改變，並尊重 `prefers-reduced-motion`。

## 6. 響應式與可及性

- 320px 至寬桌面均不產生水平溢位。
- 桌面實驗室為字形／控制與研究證據雙欄；窄螢幕改為單欄。
- 所有輸入都有可程式辨識的 label。
- 鍵盤可到達導覽、CTA、表單、案例按鈕與變體卡。
- 焦點樣式不可只依靠瀏覽器預設的低對比外框。
- 顏色不作為 PASS／FAIL 唯一訊息來源。
- 裝飾 SVG 使用 `aria-hidden="true"`；有意義圖示提供文字名稱。

## 7. 錯誤與降級

- 核心資料腳本載入失敗時，靜態介紹內容仍可閱讀；實驗室區域要顯示初始化失敗訊息，不呈現空白假介面。
- 不支援 `IntersectionObserver` 時內容直接顯示。
- 下載被瀏覽器阻擋時回報失敗，不顯示誤導性的成功訊息。
- JavaScript 關閉時，一般介紹、方法、證據說明與 FAQ 仍可閱讀。

## 8. 驗收與測試

### 自動測試

- 新增靜態網站結構測試，檢查品牌、必要章節、雙 CTA、相對資源路徑、可及性狀態區與既有 Lab DOM ID。
- 擴充互動測試，涵蓋案例載入、自動修正、手動音系衝突、變體切換與匯出回饋。
- 既有 `node tests/test_core_v0.4.js` 必須通過 30 groups。
- 既有 `python -B tools/empsl_v04_batch_check.py` 必須通過 4,096 cases。

### 真實瀏覽器驗收

- 由 `python -B -m http.server 8765 --bind 127.0.0.1` 提供頁面。
- 桌面與行動寬度各檢查一次首屏、導覽與實驗室。
- 確認無主控台錯誤、無缺失資源、主要錨點可達。
- 實際操作錯誤案例、自動修正、R90 變體與兩種匯出。

## 9. 完成定義

- Axioglyph 品牌、雙層入口與完整內容在本機 HTTP 可直接使用。
- 現有驗證功能沒有回歸；操作結果不再讓使用者猜測。
- 網站不依賴最終網域或根路徑。
- README 說明啟動、驗證、部署彈性與研究邊界。
- Git 工作樹只包含本次網站、測試與文件變更。
